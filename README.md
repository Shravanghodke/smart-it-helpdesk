
# Smart IT Helpdesk

A Python-based IT Helpdesk Ticket Management System built using Streamlit, SQLite, Pandas, and Plotly.

## Live Demo

[Open Smart IT Helpdesk](https://smart-it-appdesk-p54qtuuk9tnnvhxpphnezy.streamlit.app/)

## Features

- Create and manage support tickets
- Search and filter tickets
- Update ticket status
- Interactive analytics dashboard
- Export tickets to CSV

## Tech Stack

Python, Streamlit, SQLite, Pandas, Plotly
